# MyRBF 实验结果绘图规范

版本：`MYRBF-FIGURE-V1-20260902`

以后每组正式对比实验不能只给一个统计数字，至少同时保留下面两类完整时间曲线：

1. **目标—实际轨迹跟踪图**：统一画机身 `x/y/z` 和 `yaw/pitch/roll` 六个量。每种方法的实际轨迹用较细实线，对应目标用同色粗虚线和空心标记。目标即使与实际轨迹重合，也必须清楚可见。
2. **六轴残差—RBF 估计图**：统一画 `Fx/Fy/Fz/Tx/Ty/Tz`。RBF 估计用实线，观测残差用点线。

统计表、柱状图和最终误差仍然保留，但只能作为时间曲线的补充，不能替代完整过程。

## 固定视觉规则

- 画布固定为 16:9，适合直接加入汇报。
- 同一种方法在所有图中使用同一种颜色，并兼顾色盲可读性。
- 所有方法使用同一时间范围、坐标单位和有效行走区间。
- 行走生效区间使用浅色背景标出，切换时刻如有必要再加竖线。
- 力统一用 `N`，力矩统一用 `N m`，位置统一用 `m`，姿态统一用 `rad`。
- 图例放在图外或上方，不遮挡曲线；网格保持浅色。
- 每张图同时导出 300 dpi PNG 和矢量 PDF，并生成 `FIGURE_MANIFEST.json` 记录数据来源和时间区间。

## 数据解释边界

- 四次独立运行的目标轨迹可能不同，不能为了画面整齐强行合成一条公共目标。
- 如果实验有独立记录的外力或力矩真值，可以画“参考输入—估计值”。
- 如果没有独立真值，只能写“观测残差—估计值”，不能把残差称为真实外力。
- 单次实验必须明确写“单次运行”；有重复实验时，主曲线画均值，并增加标准差或 95% 置信区间。
- 不同方法必须来自相同地形、速度、负载、扰动和时间窗口，才允许放在同一张对比图中。

## 默认命令

```powershell
python scripts/plot_myrbf_tracking.py `
  --case Baseline=<baseline结果目录> `
  --case ETHRBF=<ethrbf结果目录> `
  --case MyRBF-v4=<v4结果目录> `
  --case MyRBF-v5=<v5结果目录> `
  --output-dir <图表输出目录>
```

默认输出：

- `01_target_actual_tracking.png/.pdf`
- `02_six_axis_estimates.png/.pdf`
- `FIGURE_MANIFEST.json`

更新汇报时生成新 PDF，不覆盖旧文件。两张时间曲线应放在对应实验结果之后、总结之前。
