# Go2 MyRBF Gazebo 仿真实验设计

日期：2026-08-30

环境：老师已有 OCS2/ROS Noetic Docker 工作区，Go2 模型，Gazebo Classic 物理仿真。

边界：这些是 Gazebo 闭环仿真，不是真实 Go2 实验。

## 1. 本轮目的

本轮不再只做单一的恒定 20 N 演示，而是依次回答四个问题：

1. MyRBF 能否估计由多个频率叠加形成的复杂外力；
2. 六维接口中的力矩方向是否已经接通；
3. Go2 在行走并承受持续负重时能否稳定运行；
4. Go2 在行走并承受不规则侧向扰动时，MyRBF 是否比 Baseline 更稳。

所有 Baseline/MyRBF 对照使用相同机器人、MPC、WBC、初始状态、步态、速度、扰动时序和记录方式。两者唯一的主要差别是 MyRBF 是否进入控制。

## 2. 新增的可重复实验能力

- 扰动脚本新增 `multisine`：两个不同频率的正弦信号叠加；
- 扰动脚本新增 `irregular`：按固定幅值和固定持续时间切换，保证每次实验完全相同；
- 新增自动运动脚本：自动切换 `static_walk`，持续发送速度命令，结束后发送零速度并切回四脚站立；
- 统一启动文件新增运动、第二频率和第二幅值参数；
- 所有新功能均有独立检查，并与原有检查一起运行。

## 3. 实验矩阵

本轮先按用户要求每个条件只运行一次，不做重复统计。

| 编号 | 运动 | 扰动 | 方法 | 主要回答的问题 |
|---|---|---|---|---|
| W0 | 0.08 m/s 静态步行 | 无 | MyRBF | 行走入口和记录链是否安全 |
| S1 | 站立 | 多频 `Fy` | Baseline | 复杂外力下的原控制表现 |
| S2 | 站立 | 与 S1 完全相同 | MyRBF | 复杂外力估计与稳定性是否改善 |
| S3 | 站立 | 周期 `Tx` | Baseline | 周期侧倾力矩下的原控制表现 |
| S4 | 站立 | 与 S3 完全相同 | MyRBF | 六维中的力矩方向是否工作 |
| W1 | 0.08 m/s 静态步行 | `Fz=-19.6 N` | Baseline | 行走负重基准 |
| W2 | 同 W1 | 与 W1 完全相同 | MyRBF | 负重能否被估计并参与控制 |
| W3 | 0.08 m/s 静态步行 | 不规则 `Fy` | Baseline | 行走复杂扰动基准 |
| W4 | 同 W3 | 与 W3 完全相同 | MyRBF | 行走复杂扰动下是否更稳 |

### 3.1 多频侧向扰动

扰动持续 6 s，开始时间为 4 s：

```text
Fy(t) = 15 sin(2π × 0.35 × τ)
      +  7 sin(2π × 1.10 × τ + π/6) N
```

其中 `τ` 是扰动开始后的时间。最大瞬时幅值不超过 22 N。

### 3.2 周期侧倾力矩

扰动持续 6 s，开始时间为 4 s：

```text
Tx(t) = 4 sin(2π × 0.5 × τ) N·m
```

### 3.3 行走等效负重

机器人在 4–13 s 之间使用 `static_walk`，指令速度为 0.08 m/s；在 6–12 s 之间向机身施加 `Fz=-19.6 N`。

该外力等效于约 2 kg 的持续重力，但没有改变模型的转动惯量，因此应称为“等效负重”，不能写成已经在模型上安装了真实 2 kg 物体。

### 3.4 行走不规则侧向扰动

机器人运动设置与负重实验相同；在 6–12 s 之间施加不规则 `Fy`。归一化幅值依次为：

```text
0, 1.0, -0.45, 0.75, -1.0, 0.3, -0.8, 0.55
```

每段持续时间依次为：

```text
0.35, 0.55, 0.25, 0.65, 0.40, 0.30, 0.50, 0.45 s
```

整个序列循环，乘以 12 N 后作为外力。这个设计同时包含方向反转、不同持续时间和不同幅值，比单次推力更能检查网络的动态跟随能力。

## 4. 记录和判断指标

每场保存四类原始数据：机身状态、MyRBF 内部记录、扰动真值和运动命令。重点检查：

- 仿真是否完整结束，机器人是否最终回到四脚站立；
- 外力调用是否全部成功；
- 最低机身高度，最大/均方根侧移、侧倾和俯仰；
- 实际轨迹与目标轨迹的差异；
- 外力估计误差和波形相关性；
- 实际进入控制的补偿量；
- 行走距离和运动结束后的恢复情况；
- 足端分配是否触发缩小或失败。

安全门槛为：控制器不异常退出、机身最低高度大于 0.25 m、结果中没有非有限控制量、扰动调用没有失败、运动结束后实际接触模式回到 15（四脚站立）。
