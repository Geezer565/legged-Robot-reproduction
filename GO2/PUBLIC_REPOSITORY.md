## 放到哪里、从哪里开始

推荐把此 `GO2/` 目录放到 `D:/GO2`，先确认没有覆盖另一份工作环境。当前 WSL 脚本使用 `/mnt/d/GO2`，而 `/workspace` 指向其中的 `code/legged_robot_workspace`。换位置需要同步调整路径，不能直接在任意克隆目录运行。

先读 [README_AGENT](README_AGENT.md) 第 3 节完成环境准备，再读 [运行命令](experi/run.md)。在 WSL 中：

```bash
bash /mnt/d/GO2/experi/scripts/run_all.sh --plan
# 确认条件后才启动整轮
bash /mnt/d/GO2/experi/scripts/run_all.sh
```

正式矩阵是 4 个条件 × 4 个方法，各运行一次，不自动重试；不是轨迹规划实验。地形接口的现有范围及未验证部分见 README_AGENT 第 6 节。
