# MyRBF V1：单残差输入设计记录

日期：2026-09-04

## 1. 本次决定

MyRBF V1 的每个轴只保留一个输入：当前时刻的归一化观测残差。

对第 `i` 个力/力矩轴：

```text
x_i(k) = r_i(k) / s_i
```

- `r_i(k)`：由相邻状态观测与 MPC 单步预测在线计算并滤波后的残差。
- `s_i`：该轴残差的尺度参数。

原第二维输入：

```text
(r_i(k) - d_hat_i(k-1)) / s_delta_i
```

已从网络输入、参数配置和诊断数据中全部删除。

## 2. 为什么删除第二维

第二维把网络上一次的估计量重新送回网络输入。它不是一个独立观测量，而是由网络自身产生，因此会形成额外的内部反馈。这样会带来三个问题：

1. 输入含义不够独立，难以说明性能提升来自新信息还是网络自身反馈。
2. 上一周期估计误差会同时影响下一周期输入和权值更新，使稳定性与参数作用更难解释。
3. 在没有专门稳定性证明和消融实验前，这一维会增加论文论证负担。

V1 使用单一、可在线直接获得的观测残差作为输入，物理意义更清楚，也更适合作为论文的第一版方法基线。

## 3. 网络结构如何调整

- 仍然是六个相互独立的子网络，分别对应 `Fx/Fy/Fz/Tx/Ty/Tz`。
- 每个子网络仍保留 25 个高斯节点和 1 个常数节点，避免同时改变网络容量。
- 25 个节点由原来的二维 `5×5` 网格改为一维等间距排列。
- 力轴中心覆盖 `[-2, 2]`，力矩轴中心覆盖 `[-4, 4]`。
- 节点宽度按相邻中心间距乘以 `width_ratio` 计算。

## 4. 哪些部分没有改变

删除的是网络输入的第二维，不是更新信号。

- 观测残差仍用于计算“残差与当前估计之差”，并驱动网络形状学习。
- 跟踪误差仍只用于常数项更新。
- 归一化、遗忘项、覆盖度冻结、权值上限和六维控制分配仍保留。

因此，V1 的核心变化是“输入从二维变为一维”，不是把整个在线更新律改成只看一个误差。

## 5. 版本与数据约定

- 原 `myrbf_shadow_v5a_go2.yaml` 已改名为 `myrbf_shadow_v1_go2.yaml`。
- V4 的两个运行配置已从当前配置目录删除。
- Baseline 和 ETHRBF 继续保留，作为后续对比方法。
- 历史 V4/V5-A 数据和分析工具保留，只用于追溯旧实验。
- 历史 V5-A 的性能结果不能直接当作 V1 结果；V1 必须重新跑实验。

## 6. 下一步实验要求

至少重新执行 Baseline、ETHRBF、V1 三种方法的同条件重复实验，包含：

1. 无扰动行走，检查 V1 不会放大原有跟踪误差。
2. 多频六维外力/力矩，检查估计和补偿效果。
3. 不同地形与等效负重，检查泛化能力。
4. V1 节点范围、宽度和学习增益的重新筛选。

当前沿用了 V5-A 的更新增益和安全限幅，但输入空间已经改变，这些参数只能作为首轮起点，不能视为已重新调优。
