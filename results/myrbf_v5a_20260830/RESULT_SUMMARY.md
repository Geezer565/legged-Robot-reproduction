# MyRBF V5-A 单次验收结果

日期：2026-09-01  
结论：**通过预先设定的单次仿真门槛，可以进入重复验证；暂时不能作为论文结论。**

## 这次完成了什么

V5-A 已经接入现有 Go2 网络，没有另起一套旁路。它把两类误差分开使用：预测误差负责学习随状态变化的形状，跟踪误差只修正整体偏差。同时加入了四层保护：按实际尺度统一学习速度、超出网络熟悉范围时暂停学习、限制内部参数幅度、保留旧配置的原行为。

新增配置位于 `legged_controllers/config/go2/myrbf_shadow_v5a_go2.yaml`。旧 V3、V4 配置不写新选项时仍按原方式工作。

## 为什么六个方向的学习参数不一样

六个方向的力和力矩量级不同，原来的输出尺度也不同。新公式会让不同方向的学习速度分别缩小约 9.8 倍到 1148.6 倍。如果仍把旧参数原样复制，六个方向实际学习速度就会严重失衡。

因此这里不是人为随意设置六组数，而是先从真实运行数据算出每个方向被缩小的倍数，再把学习参数按该倍数换算，使六个方向恢复到接近 V4 的实际学习速度。六个方向仍使用完全相同的更新规则，区别只来自各自的物理尺度。

## 验证过程

1. 修改前基线编译成功，原有 6 组测试全部通过。
2. 新增规则先用失败测试约束，再实现；偏差学习、形状学习、暂停学习、限幅和旧版本兼容均已覆盖。
3. 控制器编译成功，现有 22 项实验记录与分析测试全部通过。
4. 用无扰动、正弦和多频三组旧数据重放，共 26971 个样本；全部结果有限，最高参数占上限约 18.1%，最高暂停比例约 0.065%。
5. 依次运行无扰动观察、无扰动闭环、恒定 20 N 侧向扰动和 ±15 N 正弦侧向扰动。
6. 为了公平比较，又在当前同一容器、相同速度、相同扰动下各跑了一次 V4。

## 第一组参数为什么失败

第一组参数直接照搬 V4，但新公式已经做了尺度统一，导致学习速度被缩小约三位数。结果虽然稳定，却几乎不补偿：

| 场景 | 估计误差 | 平均补偿 | 结果 |
| --- | ---: | ---: | --- |
| 恒定 20 N | 17.653 N | 0.298 N | 学得太慢 |
| 正弦 ±15 N | 10.386 N | 0.065 N | 学得太慢 |

这组结果证明新公式不能直接沿用旧学习参数。随后依据六方向的实际缩小倍数重新换算参数，再进行全部安全检查。

## 与 V4 的同条件对比

### 正弦 ±15 N

| 指标 | V4 | V5-A | 变化 |
| --- | ---: | ---: | ---: |
| 估计误差 | 3.802 N | 3.807 N | +0.12% |
| 波形相关性 | 0.935 | 0.935 | 基本相同 |
| 侧向摆动 | 3.667 cm | 2.594 cm | **降低 29.3%** |
| 横滚摆动 | 0.886° | 0.883° | 降低 0.3% |
| 平均补偿 | 2.039 N | 2.058 N | 基本相同 |

这组满足预先写下的门槛：估计误差没有增加超过 10%，侧向摆动明显降低，同时横滚没有恶化。

### 恒定 20 N

| 指标 | V4 | V5-A | 变化 |
| --- | ---: | ---: | ---: |
| 估计误差 | 5.979 N | 5.469 N | 改善 8.5% |
| 侧向偏移 | 19.801 cm | 23.537 cm | **增大 18.9%** |
| 横滚 | 1.600° | 1.654° | 增大 3.3% |
| 平均补偿 | 2.757 N | 2.684 N | 降低 2.7% |

恒定扰动下估计更准，但机身侧向偏移更大。这是当前 V5-A 的明确短板，不能省略，也说明“估计更准”不必然等于“运动表现更好”。下一轮应检查恒定分量的补偿方向、进入速度和控制分配，而不是继续盲目增大学习参数。

## 当前判断

- V5-A 的核心设计合理，旧版本兼容、安全保护和运行记录已经完成。
- 按单次验收规则，V5-A 可以进入多次重复实验。
- 正弦扰动表现有改善，但恒定扰动仍需优化。
- 当前每个条件只有一次，不能声称统计显著，也不能直接写成论文最终结论。
- 建议下一步先重复 V4/V5-A 正弦与无扰动各 5 次，再单独解决恒定扰动问题；在此之前不启动 V5-B 控制接入。
