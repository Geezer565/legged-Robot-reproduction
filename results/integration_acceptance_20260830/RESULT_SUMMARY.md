# Go2 MyRBF 接入验收结果

日期：2026-08-30
目的：确认当前隔离版本中的 MyRBF v4 已正确进入 Go2 Gazebo 控制闭环。本轮只运行一组无扰动和一组 10 N 恒定侧向扰动，不作为论文统计实验。

## 闭环冒烟结果

| 场景 | 结果 |
|---|---:|
| 无扰动记录 | 557 个 RBF 样本、400 个状态样本 |
| 无扰动最大侧移 | 0.220 cm |
| 无扰动最大侧倾 | 0.265° |
| 无扰动最低机身高度 | 0.3438 m |
| 无扰动最大侧向补偿 | 0.258 N |
| 10 N 扰动记录 | 920 个 RBF 样本、500 个状态样本 |
| 10 N 扰动调用 | 150/150 成功 |
| 10 N 扰动期间平均估计 | -8.331 N |
| 10 N 扰动结束前估计 | -9.064 N |
| 10 N 扰动估计误差 | 1.888 N |
| 10 N 扰动期间平均实际补偿 | -2.066 N |
| 10 N 扰动最大侧移 | 1.192 cm |
| 10 N 扰动最大侧倾 | 0.826° |
| 足端分配最小比例 | 1.0，未触发缩小 |

网络估计和实际补偿均为负方向，与抵消 `+10 N Fy` 外力所需方向一致。当前配置只施加估计的一部分，因此平均实际补偿约为 `-2.07 N`，这是有意保留的安全余量，不表示网络只能估计 2 N。

两场实验均加载六维接口和补偿感知观察器，机器人保持站立，没有触发控制器安全退出。Baseline 的已保存同接口数据有 1554 个样本，实际侧向补偿最大值为 0，证明关闭控制补偿后可以退回原控制链。

## 结论边界

本轮证明的是接入位置、数据方向、六维分配和安全开关可以正常工作。它不是重复统计实验，也不证明真机、行走、负重和多地形已经完成。
